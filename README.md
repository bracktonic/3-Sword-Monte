# 3 Sword Monte

A turn-based medieval card battle game for the command line.

## Rules

- You control three units on a battlefield.
- Each unit has 6 hit points.
- Each unit has access to two hidden stances, represented twice across the three units.
- Each turn, your chosen unit declares three attacks.
- Each attack is Rock (R), Paper (P), or Scissors (S).
- Attack outcomes:
  - Win: 2 damage to the opponent
  - Tie: 1 damage to both units
  - Loss: no damage
- Defeat all three enemy units to win.

## Play

Run the game with Python:

```bash
python three_sword_monte.py
```

Choose your active unit and enter three attacks each turn.

Good luck on the field of battle.
